PostbankFinder — cross-origin DOM XSS on www.postbank.de

Authorized security research · Postbank bug-bounty scope (*.postbank.de) · proof fires alert(document.domain) only
The vulnerability

The PostbankFinder locator on www.postbank.de has a window "message" handler with no origin check: it stores the attacker's scrollY from JSON.parse(event.data), then attachTooltip() interpolates it raw into style="top:${scrollY}px;" in the tooltip HTML. A " in scrollY breaks out and injects HTML into the page. No script-src CSP → the <img onerror> runs. Needs the mobile layout (innerWidth<984, so an 820px popup) and a search to render the tooltip.

Exploit chain
  1. Attacker page opens the finder in an 820px popup (innerWidth<984 → mobile layout).
  2. postMessage(JSON.stringify({type:"viewchange", scrollY: PAYLOAD})) — no origin check → stored.
  3. Victim runs a search → a result tooltip renders → attachTooltip() writes top:${scrollY}px;" raw.
  4. scrollY breaks out of the attribute → <img src=x onerror=alert(document.domain)> executes in the www.postbank.de origin.
